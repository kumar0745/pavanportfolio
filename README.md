# Pavan Kumar — Portfolio repository

The repository has been initialised with a GitHub Pages deployment workflow and upload instructions. The complete website source and media assets are included in the full release ZIP supplied in this conversation.

## Upload the complete website

Download and extract the portfolio release bundle, then run `PUSH_TO_GITHUB.bat` from the extracted `pavan-kumar-portfolio` folder. It copies the full website into a Git checkout and pushes the complete project to this repository's `main` branch. See [GITHUB_UPLOAD_GUIDE.md](GITHUB_UPLOAD_GUIDE.md).

## After upload

In **Settings → Pages**, set **GitHub Actions** as the build and deployment source. The included workflow publishes the static site from `main`.

## Privacy

This repository is public. The portfolio bundle includes your supplied resume with email/phone details, presenter portrait and intro video. Review these files before making the complete source visible to everyone.
