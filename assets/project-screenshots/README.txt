PROJECT SCREENSHOT ASSETS

NeuroDetect is connected to https://neurodetect.lovable.app/. Its portfolio image uses an on-demand Thum.io page screenshot URL configured in assets/project-config.js. The image is requested when the portfolio is viewed; it is not a locally stored screenshot. The direct live-site link remains available if the screenshot endpoint is unavailable.

Other application images in assets/project-previews/ are illustrative concepts, not screenshots of deployed apps. Do not relabel them as live website captures.

To add a local website screenshot, save a WebP image here using the corresponding filename (for example, agrisolve-overview.webp) and update the project's screenshot path in assets/project-config.js. Keep liveUrl separately so visitors can open the actual application.
