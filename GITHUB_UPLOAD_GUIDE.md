# Complete portfolio upload

The initial GitHub setup and GitHub Pages workflow have been committed. The complete HTML, CSS, JavaScript, Three.js scene and media assets are in the full portfolio release bundle provided in this conversation.

1. Download and extract the full portfolio bundle.
2. Open the extracted `pavan-kumar-portfolio` folder.
3. Double-click `PUSH_TO_GITHUB.bat`.
4. Sign in to GitHub in the browser if Git Credential Manager asks.
5. Wait for the script to report SUCCESS.

The script clones this repository into a neighbouring folder named `pavanportfolio-github`, copies the full source and assets, commits the result, and pushes to `main`. It leaves the extracted source folder unchanged.

Requirements: Git for Windows and push permission on this repository.

Privacy reminder: this public repository contains the supplied resume, which includes contact details, as well as a portrait and intro video. Anyone can view and download public repository contents.
